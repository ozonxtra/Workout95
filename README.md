# Spesialisasi 95 · Habit Tracker Latihan

PWA statis tanpa build. Semua file ada di akar repo (`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `vercel.json`).

Impor repo ini di https://vercel.com/new → Framework Preset **Other** → biarkan Build Command dan Output Directory kosong → Deploy.
